# Introduction to Python — Notebook Overview

Purpose
-------

This notebook is an introductory, hands-on guide to core Python fundamentals for beginners. It demonstrates essential concepts with short, self-contained examples and explanatory markdown so learners can run and experiment with code interactively.

Audience
--------

- Absolute beginners learning Python syntax and basic programming concepts.
- Students transitioning from JavaScript who want side-by-side comparisons.

What the notebook contains
-------------------------

- Setup & quick environment tests (first cell).
- Variables and basic data types (strings, integers, floats, booleans).
- Conditional statements and logical operators with examples.
- Lists and indexing, plus iteration with `for` loops.
- Dictionaries (key/value storage) and iterating with `items()`.
- Function definitions, parameter passing, and return values.
- Small, runnable examples and short explanatory comments to reinforce each concept.

How to use
----------

1. Open the notebook in Jupyter, VS Code, or Google Colab.
2. Run cells sequentially to see printed outputs and type information.
3. Modify example values to experiment and observe different outputs.

Notes
-----

- Some cells include JavaScript examples for direct syntax comparison; these are explanatory and can be converted to Markdown if you only want Python examples.
- The notebook is intentionally small and focused; use it as a starter template for exercises or demonstrations.
